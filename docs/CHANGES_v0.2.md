# v0.2 변경 내역 — v0.1 검증 결과와 수정

v0.1(원본 커밋 86bc9df)을 코드 전체 정독, 테스트 실행(20개 통과), 별도 실험으로 검증했다. 아래 문제는 모두 **실제 실행으로 재현**했고, 각 수정은 회귀 테스트로 고정했다.

## 사소한 것

- 입력 검사가 None·문자열·미지 노드에서 TypeError/KeyError 대신 ValueError를 냄. 자기 연결 링크 거부, 고장 수원이 실제 수원인지 확인.
- 예산 민감도·운영 재최적화 버튼 예외 처리.
- 위험 화면의 지역 간 연결 수를 실제 망에서 계산(하드코딩 0 제거), 저장 일수 표시.
- 코드 서식을 한 줄 몰아쓰기에서 읽을 수 있는 형태로 정리(engine, quality, demo, reporting, app).
- Streamlit 최소 버전을 실제 검증한 1.66으로 올림(`width="stretch"` 사용).

## 그대로 둔 v0.1의 좋은 점

가짜 확률·가짜 성능 수치 금지, `GRAPH_FEASIBLE`/`NOT_VALIDATED` 정직한 표시, 독립 물량 검증기, 반사실적 재최적화, 입력·코드 해시 기반 실행 ID, 원수/정수 계층 분리.

## 아직 남은 것

WNTR/EPANET 수압 검증, 재난 중 매일 다시 계산하는 MPC, 실제 댐 저수량·유입 시계열, 저장·펌프 증설 후보, 위험 점수, 보정된 축소모형 용량.
