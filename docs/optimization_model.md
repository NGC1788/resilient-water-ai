# 계산 모델

투자 이진변수 y[a]는 모든 시나리오·날짜가 공유한다. 운영변수는 시나리오 s, 날짜 t별 취수 q, 링크 흐름 f, 공급 x, 전체 부족 u, 필수 부족 h, 저장 S다. 미래 시나리오에 따라 투자를 달리 고를 수 없다.

## 제약

- CAPEX = Σ cost[a] y[a] ≤ B. enabled=false, DENIED, 삭제 실험 후보는 y=0.
- 배타 옵션별 Σy≤1. 후보 f≤capacity*y, 기존 f≤capacity. 고장 링크 f=0.
- 수원 q≤yield*scenario_factor. 기간 취수 합계≤기간 수율 총량.
- 일반 노드: 유입−유출=0. 수원: 유입+q−유출=0.
- 수요: 유입−x=0, x+u=demand, x+h≥essential, 0≤x≤demand.
- 배수지: S[t]=S[t−1]+유입−유출, Smin≤S≤Smax. 각 시나리오 초기 저장량은 동일한 주어진 관측/가정값이다.
- 원수→정수 변환은 정수장 처리 링크에서만 허용. 처리 링크 용량이 처리 한계다. 처리 수율 1의 단순화.

## 사전식 강건 목적

1. max_s Σ(t,i) h[s,t,i] 최소화
2. 1의 최적값을 고정하고 max_s Σ(t,i) u[s,t,i] 최소화
3. 1~2를 고정하고 Σ(s,t,i)h 최소화
4. 1~3을 고정하고 Σ(s,t,i)u 최소화
5. 앞선 목적 고정 후 (CAPEX+Σ(s,t,e) OPEX*f)/1억원 최소화

앞선 최적값의 허용오차는 절대 1e-6이다. SciPy milp의 HiGHS 솔버, 상대 MILP gap=0, 단계당 제한시간 120초. 최적성이 확인되지 않으면 성공으로 표시하지 않고 오류를 반환한다. 기대값이나 재난 확률은 계산하지 않는다. OPEX 합계는 시나리오 합계의 결정적 tie-break이며 확률 기반 연간 비용이 아니다. 모든 시나리오는 동일한 일수로 비교한다. 화면의 m³/일 지표는 기간 총 부족/기간 일수이며, 특정 날짜의 순간 최대 부족과 다르다.

상위 대안: 앞선 이진 투자 조합을 no-good cut으로 배제하고 전체 MILP를 재실행한다. 반사실적: 선정 후보 하나를 금지한 뒤 나머지 투자·운영을 동일 예산·시나리오에서 재최적화한다. 따라서 단순한 시설 폐쇄에 대한 고정망 손실과는 다른 질문에 답한다. 실측 운영 재계산은 기존 선정 y를 고정한다.

Independent validator는 솔버 제약 행렬을 재사용하지 않고 출력 records로 질량보존, 후보/고장 용량, 취수율, 수요 상한, 필수 부족 산식, 저장 한계를 다시 검사한다.
