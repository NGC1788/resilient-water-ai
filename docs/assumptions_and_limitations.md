# 가정·미구현

원본 명세의 P0를 우선 구현한다. 명세에 적힌 P1~P4를 구현 완료로 주장하지 않는다.

- 자료·비용·좌표·고도는 완전 가상이다. 공사비는 옵션별 2~4억원의 합성 입력이고 시장 견적·거리 기반 실제 추정이 아니다. 불확실성 ±50%는 분포 추정이 아닌 데모 가정이다.
- 물량 단위는 m³/일, 저장량 m³. 일단위 기간 내 유입·수요는 일정하다. 정수 처리 손실·수질 반응·압력·수두·관경·에너지 곡선·하천 수리·계절 유입은 계산하지 않는다.
- 투자 옵션 용량은 이산 고정 옵션이다. UI에서 용량을 지정할 수 있으나 연속 관경/노선 최적화는 아니다. 신규 저장/펌프/대체 수원 옵션 최적화는 P0 이후 확장이다.
- 초기 저장량은 모든 시나리오에 동일하다. 종말 저장은 최소 저장량까지만 보장하므로 긴 기간·반복 재난에는 재충전·종말 목표를 추가해야 한다.
- 권역 선택은 필수 보호 수요 우선순위만 변경하고 기존 물리망·일반 수요는 보존한다. 별도 농업 망은 없다.
- 위험 화면은 수요·가뭄 공급차·대체망 지표를 공개하며 확률 점수·AI 예측은 만들지 않는다. 예측 학습이 없으므로 미래 관측 누출 검사는 비적용이다.
- 포화 링크는 제약 근접성 근거이며 인과적 병목이나 그림자 가격을 의미하지 않는다. 개별 미선정 자산에 대한 강제 선정 실험은 미구현이며 추측한 설명을 만들지 않는다.
- 예산 민감도는 UI 실행 시 실제 재계산한다. 비용 불확실성의 확률 분석·전국 확장·상세 인허가·수리권·환경 검증은 미구현이다.
- 독립 HTML은 오프라인 스크립트를 포함한다. PDF 직접 생성기는 미구현이나 HTML에서 인쇄할 수 있다.
- 정식 FAIR 카탈로그·자료 수입·이상 시계열 고착/지연/시간 역전 검사·공간 관계 DB·과거 대응 이력 검색·PostGIS·WNTR/EPANET은 P1~P3 작업이다.
- 실제 건설/운전 승인용이 아니며 하드웨어 연결은 제외했다.
