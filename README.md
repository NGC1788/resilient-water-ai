# RESILIENT WATER AI — P0

재난 **이전**에 신규 연결·증설·우회 송수관 후보를 선택하고, 모든 개발 시나리오에서 공통으로 쓸 투자망과 각 재난의 배분 계획을 계산하는 한국어 의사결정 지원 소프트웨어입니다. 결과·대안·반사실적 설명은 SciPy/HiGHS MILP 계산에서 생성합니다.

**전부 가상 데이터이며 개념 설계입니다. 실제 전국 인프라·GIS 노선·공사비·인허가·압력 검증 결과가 아닙니다.** 물량 보존 검증은 `GRAPH_FEASIBLE`, 물리 모델은 `CONCEPTUAL_ONLY`, 수리 검증은 `NOT_VALIDATED`로 구분합니다. 실제 시설 연결 및 제어는 없습니다.

## 실행

Python 3.12 이상을 준비한 뒤 저장소에서:

```sh
python -m pip install -e ".[test]"
python run.py
```

설치 후 **실행 명령은 `python run.py` 하나**입니다. 브라우저에서 표시된 로컬 주소를 열고 **사전 대비망 설계 스튜디오 → 사전 대비망 설계**를 실행합니다. 인터넷 없이 계산·시각화·독립 HTML 출력이 가능합니다(최초 패키지 설치에는 인터넷 필요).

```sh
python run.py --test       # 자동 검증
python run.py --report     # 기본 입력으로 실제 계산 후 reports/ 생성
```

## 포함된 기능

- 가상 3개 유역/급수권역, 수원 3개, 정수장 3개, 배수지 3개, 수요지역 6개, 기존 링크 15개, 후보 신설/증설/우회 링크 6개.
- 원수 → 정수처리 → 정수 송배수 계층 분리. 명시된 정수 처리 변환 외 원수·정수 혼합 금지.
- NORMAL, LONG_DROUGHT, PIPE_BREAK, COMPOUND의 공통 시설 선택 MILP. 개발에 사용하지 않은 극단 시나리오도 고정 투자망에서 검증.
- 일별 취수·링크 흐름·공급·필수/전체 부족·비상 저장량 및 독립 물량 검증.
- 필수 부족 최악값 → 전체 부족 최악값 → 합계 필수 부족 → 합계 전체 부족 → 투자·운영비의 사전식 최적화.
- 예산, 선택 전 후보 유량 차단, 금지 인허가, 상호 배타 옵션, 취수·정수·관로·저장량 제약.
- 서로 다른 투자 조합 상위 3개(가능 조합이 부족하면 이유 표시), 무투자 기준망 비교.
- 선정 시설마다 **동일 예산·동일 재난 아래 해당 후보를 금지하고 나머지 투자까지 재최적화**. 차이가 0이면 대체 가능성을 그대로 표시.
- 한국어 9개 화면, 후보 활성화/비활성화·용량·비용 수정·사용자 후보 추가, 시나리오 고장 편집, 보호 권역·필수 수요·예산·기간 변경.
- 논리 좌표 지도/그래프: 기존 실선, 선정 후보 초록 점선, 미선정 회색 점선. 일별 계산 유량 열람.
- JSON/CSV/GeoJSON/독립 HTML 보고서; HTML 브라우저 인쇄로 PDF 저장 가능. 실제 좌표가 없어 GeoJSON은 `geometry=null`.
- 입력·시나리오 SHA-256, 알고리즘 버전, 실행 ID, 솔버 상태·gap, 최적화 단계 기록, 계산 열과 설명 근거 연결.

## 기본 계산 결과

`reports/preparedness-plan.html`은 `python run.py --report`가 실제 생성한 결과입니다. 정해진 성능 수치를 UI에 하드코딩하지 않습니다. 결과 수치는 보고서와 JSON에서 확인하세요. 입력을 바꾸면 실행 ID와 계산이 변경됩니다.

## 범위와 남은 작업

최상위 제품 요구사항은 `docs/RESILIENT_WATER_CODEX_SPEC_V2.md`입니다. 이번 구현은 P0이며 P1~P3 전체 완료를 의미하지 않습니다. FAIR 카탈로그 DB·실제 데이터 수입·공간 매핑·학습 예측·과거 대응 이력·WNTR/EPANET 수압 검증은 미구현입니다. 저장 증설·펌프곡선·GIS 노선 자동 생성도 현재 제공하지 않습니다. 자세한 제한과 P0 요구사항 대응은 `docs/validation.md` 및 `docs/assumptions_and_limitations.md`에 있습니다.

개념 후보의 허가 `UNCONFIRMED`는 건설 허용을 뜻하지 않습니다. `DENIED`는 투자 선정 금지입니다. 예산·피해 감소가 같아도 여러 최적 유량 해가 있을 수 있습니다. 실행 ID는 입력/알고리즘의 식별자이며 실측 검증의 증명이 아닙니다.
